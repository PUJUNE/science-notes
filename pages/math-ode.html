Field 01 · 수학 · 미분방정식과 적분법

변수분리는 약분이 아니라 치환적분

dy/dx를 분수처럼 갈라 놓고 양변을 각각 적분하는 절차는 계산으로는 익숙하지만, 왜 그래도 되는지는 따로 설명되지 않는 경우가 많음. 이 페이지는 그 절차를 연쇄법칙까지 거슬러 올라가 정당화하고, 얻은 해가 방향장 위에서 어떤 곡선족을 이루는지 그려 봄.

∫ (y′/y) dx = ∫ dx → ln|y| = x + c → |y| = ex+c

01 변수분리법

같은 식을 두 갈래로 풀어도 결과가 같음

다루는 방정식은 y′ = y임. 이 식을 y로 나누면 좌변이 y′/y 형태가 되는데, 여기서부터 두 갈래의 풀이가 갈라짐. 하나는 양변을 그대로 x에 대해 적분한 뒤 좌변에만 치환적분을 적용하는 정공법이고, 다른 하나는 dy/dx를 분수처럼 취급해 dx를 넘긴 뒤 양변을 각각 적분하는 변수분리법임. 두 갈래는 표기만 다르고 실제로 수행하는 연산은 같음.

경로 A 양변을 x로 적분
  • 1. 양변을 x로 적분 — ∫(y′/y)dx = ∫1dx
  • 2. 좌변에 치환적분 적용 — ∫(1/y)dy로 변환
  • 3. 각각 적분 — ln|y| + C₁ = x + C₂
  • 4. 상수 통합 — ln|y| = x + c
경로 B 변수분리
  • 1. y′ → dy/dx — (1/y)(dy/dx) = 1
  • 2. 양변에 dx를 곱함 — (1/y)dy = 1dx
  • 3. 양변에 적분 기호 — ∫(1/y)dy = ∫dx
  • 4. 각각 적분 — ln|y| = x + c

경로 B의 2단계가 문제가 되는 지점임. dy와 dx는 각각 독립된 양이 아니라 극한 기호의 일부이므로, 분수처럼 곱하고 나누는 조작 자체에는 근거가 없음. 그럼에도 결과가 맞는 이유는 이 표기가 경로 A의 치환적분 과정을 압축해 적어 놓은 것이기 때문임. 즉 변수분리는 새로운 정리가 아니라 치환적분의 축약 표기임.

읽는 법 — 단계를 넘기면 좌변이 x에 대한 적분에서 y에 대한 적분으로 바뀌는 지점이 표시됨. 이 변환이 일어나는 곳이 치환적분이 들어가는 자리이며, 변수분리법에서는 이 단계가 눈에 보이지 않게 생략됨.

02 치환적분

dx 위의 균등 분할이 dy 위에서는 불균등해짐

치환적분이 하는 일을 리만 합으로 보면 분할의 재배치임. 좌변 ∫f(y)(dy/dx)dx는 x축을 균등하게 나눈 뒤 각 조각에 f(y)·(dy/dx)를 곱해 더하는 계산이고, 우변 ∫f(y)dy는 y축을 나눈 뒤 f(y)만 곱해 더하는 계산임. 두 합이 같아지는 것은 (dy/dx)Δx가 곧 그 구간에서 y가 움직인 폭 Δy이기 때문임.

∫ f(y) (dy/dx) dx = ∫ f(y) dy
— (dy/dx)Δx ≈ Δy 이므로, x축 균등 분할이 y축에서는 기울기에 비례해 늘어나거나 줄어듦

y가 빠르게 증가하는 구간에서는 같은 폭의 Δx가 훨씬 넓은 Δy로 대응되고, 완만한 구간에서는 좁게 대응됨. 이 신축을 담당하는 항이 dy/dx이며, 그래서 이 항이 곱해진 형태의 적분만 dy 적분으로 바꿔 쓸 수 있음.

03 연쇄법칙 역추적

치환적분은 합성함수 미분을 거꾸로 읽은 것

앞 절의 등식은 다음 네 단계로 증명됨. 출발점은 원시함수의 정의이고, 도착점은 두 적분이 같은 함수 F(y)로 수렴한다는 사실임.

1. 원시함수 정의   (d/dy) F(y) = f(y)
2. 연쇄법칙        (d/dx) F(y) = (d/dy)F(y) · (dy/dx) = f(y)(dy/dx)
3. 미분의 역연산   ∫ f(y)(dy/dx) dx = F(y) + C
4. 정의로 회귀     ∫ f(y) dy = F(y) + C
3과 4의 우변이 같으므로 좌변끼리도 같음
  • F(y)f(y)를 y에 대해 적분한 원시함수
  • f(y)피적분함수. 여기서는 1/y
  • y(x)x에 종속인 함수. 단순한 문자가 아니라 종속변수임
  • dy/dx속함수 y의 도함수. 연쇄법칙에서 곱해지는 인자
  • C적분상수. 두 식에서 각각 나오지만 하나로 묶어 표기함

2단계가 이 증명의 축임. F(y)를 x로 미분할 때 y가 x의 함수이므로 겉함수 F 안에 속함수 y가 들어간 합성함수가 되고, 여기서 dy/dx가 곱해져 나옴. 3단계는 이 미분을 되돌린 것이므로 dy/dx가 곱해진 형태가 그대로 등장할 수밖에 없음.

정리 — (dy/dx)dx가 약분되어 dy만 남는 것처럼 보이는 계산은 기호의 우연이 아니라 합성함수 미분의 역과정임. 그래서 변수분리 후 양변을 각각 적분해도 등식이 유지됨.

04 방향장과 해곡선

방정식은 기울기만 정하고, 곡선은 초기조건이 고름

y′ = f(x, y) 형태의 1계 미분방정식은 평면의 각 점에서 해곡선이 가져야 할 기울기를 지정함. 그 기울기를 짧은 선분으로 평면에 뿌린 것이 방향장이고, 해를 구한다는 것은 이 선분들을 매끄럽게 이어 붙인 곡선을 찾는 일임. 방정식 하나가 곡선 하나가 아니라 곡선족을 낳는 이유가 여기 있음 — 어느 점을 지나느냐에 따라 서로 다른 곡선이 나옴.

y′ = y를 고르면 기울기가 y에만 의존하므로 방향장이 가로 방향으로 균일해지고, 해는 y = Cex 꼴이 됨. y′ = −2xy를 고르면 기울기가 x에도 걸려 가우스 형태 y = Ce−x²가 나옴. 두 경우 모두 C는 초기조건이 정하고, 방정식 자체는 C에 대해 아무 말도 하지 않음.

05 적분상수

지수로 올라간 상수는 곱셈 상수가 됨

ln|y| = x + c의 양변에 지수를 취하면 |y| = ex+c = ecex가 됨. ec는 c가 실수인 한 항상 양수이므로, 절댓값을 벗기면서 부호를 흡수시켜 y = Cex로 쓰고 이때 C는 0이 아닌 임의의 실수가 됨. C = 0도 y = 0이라는 자명해에 해당하므로 최종적으로 C는 임의의 실수로 확장됨.

ln|y| = x + c
|y| = ex+c = ec · ex
y = C ex   C = ±ec, 그리고 자명해 y=0을 포함해 C ∈ ℝ
단계식상수의 지위
적분 직후ln|y| + C₁ = x + C₂양변에 각각 하나씩
이항·통합ln|y| = x + cc = C₂ − C₁, 덧셈 상수
지수화|y| = ecexec > 0, 곱셈 상수
절댓값 해제y = CexC = ±ec, 부호 흡수
자명해 포함y = CexC ∈ ℝ

해곡선족이 서로 교차하지 않는 점을 확인해 볼 것. 평면의 각 점에서 기울기가 하나로 정해지므로 두 해곡선이 한 점에서 만나면 그 점에서 기울기가 둘이 되어 모순임 — 해의 유일성이 그래프 위에 그대로 나타남.
