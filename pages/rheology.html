Field 07 · 물리 · 레올로지와 도공 공정

점도는 상수가 아니라 전단속도의 함수

같은 젤이 노즐에서는 묽게 흐르고 전극 위에서는 굳은 듯 버티는 거동은 두 지점의 전단속도가 다르기 때문임. 이 페이지는 전단응력과 전단속도의 관계를 네 가지 모델로 세우고, 그 관계가 회전 점도계 판독과 도공 두께 설계로 어떻게 이어지는지 계산으로 따라감.

τ = τ₀ + K·γ̇n   — Herschel–Bulkley. n, τ₀의 값에 따라 나머지 세 모델을 모두 포함함

01γ̇ = dv/dy

전단 유동의 정의

두 평행판 사이에 액체를 채우고 위판만 일정 속도로 끌면, 액체 속도가 아래판의 0에서 위판의 U까지 두께 방향으로 층층이 달라짐. 이 속도 기울기가 전단속도이고, 위판을 끄는 데 필요한 단위 면적당 힘이 전단응력임. 점도는 두 양의 비로 정의되며, 이 정의 자체에는 점도가 상수라는 조건이 들어 있지 않음.

γ̇ = dv/dy = U / h   — 전단속도 [s⁻¹]
τ = F / A           — 전단응력 [Pa]
η = τ / γ̇          — 겉보기 점도 [Pa·s]
  • γ̇전단속도 [s⁻¹]. 속도 기울기이므로 시간의 역수 차원임
  • τ전단응력 [Pa]. 유동 방향으로 층을 미는 단위 면적당 힘
  • η겉보기 점도 [Pa·s]. 1 Pa·s = 1000 cP
  • U위판 속도 [m/s]
  • h판 간격 [m]

전단속도의 크기는 공정 지점마다 자릿수 단위로 갈림. 통에 담긴 젤이 자중으로 천천히 처지는 구간은 0.01 s⁻¹ 아래이고, 스무더 간극을 통과하는 순간은 라인 속도를 간극으로 나눈 값이라 수백 s⁻¹에 이름. 같은 재료라도 두 지점에서 잰 점도가 다르게 나오는 이유가 여기 있으므로, 점도 값은 전단속도를 함께 적지 않으면 판독이 성립하지 않음.

정치 중 자중 처짐낮음구동 속도가 없고 중력만 걸림
저속 교반·숙성중간임펠러 선속도를 용기 간극으로 나눔
스무더 간극 통과높음라인 속도 U를 간극 h로 나눈 U/h
도포 직후 레벨링낮음구동력이 표면장력과 자중만 남음

02η = const ?

뉴턴 유체와 비뉴턴 유체

전단응력이 전단속도에 정비례해 점도가 전단속도와 무관하게 일정한 유체를 뉴턴 유체라 부름. 물과 글리세롤 수용액이 여기 가까움. 고분자 사슬이나 입자가 들어가면 유동 중에 사슬이 흐름 방향으로 정렬하거나 얽힘이 풀리면서 점도가 전단속도에 따라 움직이고, 이때부터 비뉴턴 거동이 됨.

n = 1 뉴턴
  • τ = K·γ̇
  • η가 전단속도와 무관
  • 물, 글리세롤 수용액
  • 로그–로그 도표에서 기울기 1
n < 1 전단담화
  • τ = K·γ̇n
  • 전단이 빨라지면 묽어짐
  • 고분자 용액, 점증제 첨가 젤
  • 도공 적성의 근거가 되는 거동
n > 1 전단농후
  • τ = K·γ̇n
  • 전단이 빨라지면 뻑뻑해짐
  • 고농도 입자 분산계
  • 고속 토출에서 압력이 급증함
τ₀ > 0 항복응력형
  • τ = τ₀ + K·γ̇n
  • 임계 응력 전에는 흐르지 않음
  • 충전제·젤 네트워크가 있는 계
  • 도포 후 처짐을 막는 성분

네 거동은 별개의 식이 아니라 하나의 식에서 파라미터만 달리 잡은 경우임. τ₀ = 0, n = 1이면 뉴턴, τ₀ = 0이면 멱법칙, n = 1이면 Bingham, 둘 다 살아 있으면 Herschel–Bulkley가 됨. 다음 절에서 이 관계를 곡선으로 확인함.

03τ = K·γ̇ⁿ

멱법칙과 전단담화

멱법칙은 전단응력을 전단속도의 거듭제곱으로 놓는 두 파라미터 모델임. 지수 n이 1에서 얼마나 떨어져 있는지가 비뉴턴 정도를 나타내고, K는 같은 전단속도에서의 응력 수준을 정함. 겉보기 점도를 다시 쓰면 점도 자체가 γ̇의 거듭제곱이 되어 로그–로그 도표에서 직선이 됨.

τ = K·γ̇n
ηapp = τ/γ̇ = K·γ̇n−1   — log η = log K + (n−1) log γ̇, 기울기가 n−1
  • K점조도 계수 [Pa·sⁿ]. γ̇ = 1 s⁻¹에서의 응력과 같음
  • n유동 지수 [무차원]. n < 1 담화, n = 1 뉴턴, n > 1 농후
  • η_app겉보기 점도 [Pa·s]. 그 전단속도에서만 성립하는 값

n − 1이 점도 곡선의 기울기이므로, n이 0.5면 전단속도가 100배 오를 때 점도가 10분의 1로 떨어짐. 도공에서 필요한 조합이 여기서 나옴. 노즐과 스무더 간극에서는 전단속도가 높아 점도가 내려가야 고르게 펴지고, 도포 후 정지 상태에서는 전단속도가 0에 가까워 점도가 다시 올라가야 전극 위에서 흐르지 않음.

실험실 배치에서 점도를 확보한 조성이라도 설비 토출 단계에서 젤이 전극 위에 고르게 펴지지 않고 응집된 채 나와 한쪽으로 쏠리거나 두껍게 쌓인 채 경화될 수 있음. 점도 조건은 소량 배치의 물성 확인에서 끝내지 말고 스케일업 배치로 토출 거동까지 확인해야 하며, 점도를 올리는 것만으로 계면 침투가 막히지 않는 경우에는 pH·Cl⁻ 조정 같은 화학 경로로 전환하는 판단이 필요함.

04τ < τ₀ → γ̇ = 0

항복응력과 Herschel–Bulkley

젤 네트워크나 충전제가 만든 구조가 있는 계는 응력이 일정 값을 넘기 전까지 흐르지 않고 탄성체처럼 변형만 함. 이 임계값이 항복응력 τ₀이며, 응력을 τ₀만큼 먼저 상쇄한 뒤 남는 몫이 유동을 만든다고 보는 것이 Herschel–Bulkley 모델임. n = 1로 두면 Bingham 소성체가 됨.

τ = τ₀ + K·γ̇n   (τ > τ₀)
γ̇ = 0                 (τ ≤ τ₀)
ηapp = τ₀/γ̇ + K·γ̇n−1   — γ̇ → 0에서 발산함
  • τ₀항복응력 [Pa]. 이 값 아래에서는 유동이 시작되지 않음
  • K점조도 계수 [Pa·sⁿ]
  • n유동 지수 [무차원]
모델파라미터 조건τ–γ̇ 관계저전단 거동
뉴턴τ₀ = 0, n = 1τ = K·γ̇점도 일정
멱법칙τ₀ = 0τ = K·γ̇nn < 1이면 점도가 계속 상승
Binghamn = 1, τ₀ > 0τ = τ₀ + K·γ̇τ₀ 아래에서 정지
Herschel–Bulkleyτ₀ > 0, n 자유τ = τ₀ + K·γ̇nτ₀ 아래에서 정지 + 담화

항복응력이 있으면 도포 후 자중으로 인한 처짐을 응력 비교만으로 판정할 수 있음. 두께 h인 젤 층이 경사 α의 면 위에 놓였을 때 바닥면에 걸리는 전단응력은 ρ·g·h·sin α이므로, 이 값이 τ₀보다 작으면 층이 그대로 멈춰 있음. 점도를 올려 처짐을 막는 방식과 달리, 항복응력은 정지 상태에서만 작동해 고전단 구간의 토출 저항을 함께 끌어올리지 않음.

측정상의 주의 — 회전 점도계로 얻는 값은 그 회전수에 대응하는 한 점의 겉보기 점도이지 τ₀와 n을 분리한 값이 아님. 모델 파라미터를 얻으려면 회전수를 바꿔 가며 여러 점을 잡고 곡선을 맞춰야 하며, 한 점만 남긴 기록으로는 모델 판별이 되지 않음.

05η = Ksp × (100/rpm) × 토크%

회전 점도계 측정 조건

점도는 Brookfield DV2T·DV2Plus 같은 회전 점도계로 측정하며, 측정값만 남기지 않고 스핀들 번호· 회전수·토크·레인지·측정일과 온도를 한 줄로 함께 기록해야 판독이 성립함. 회전 점도계가 실제로 계측하는 물리량은 스프링의 비틀림에서 나오는 토크 비율이고, 점도는 스핀들 상수와 회전수로 환산한 값임.

η [cP] = Ksp × (100 / rpm) × 토크[%]
측정 상한 = Ksp × 10000 / rpm   — 토크 100 %에 해당하는 점도
  • K_sp스핀들 상수. LV-1 = 6, LV-2 = 30, LV-3 = 120, LV-4 = 600
  • rpm회전수 [min⁻¹]. 전단속도를 정함
  • 토크%스프링 최대 토크 대비 비율. 유효 판정 구간은 10~90 %
기록 항목판독에서 맡는 몫
스핀들 번호시료 점도대에 맞는 전단 면적을 지정함. 저점도 시료는 LV-02(62), 고점도 용액은 LV-04(64)처럼 계열 내에서 바꿔 잡음
회전수(rpm)전단 속도를 정함. 같은 스핀들에서 회전수를 낮추면 측정 레인지가 넓어지고 토크는 내려감
토크(%)측정이 유효한지 판단하는 지표. 토크가 지나치게 낮으면 회전수를 올리거나 작은 레인지 조합으로 바꿔 다시 잡음
레인지(cP)스핀들·회전수 조합이 만드는 측정 상한. 시료 점도가 상한에 접근하면 조합을 바꿔 여유를 확보함
측정일·측정 온도점도의 온도 의존성과 숙성 경과를 함께 읽기 위한 기준

토크가 유효 구간을 벗어나면 값 자체를 버리고 조합을 다시 잡아야 함. 토크가 10 % 아래면 스프링 변위가 작아 분해능이 떨어지고, 90 %를 넘으면 상한에 붙어 실제 점도가 더 높아도 값이 늘지 않음. 조합을 바꾸는 방향은 두 갈래로, 점도가 높으면 큰 상수의 스핀들이나 낮은 회전수를, 점도가 낮으면 작은 상수의 스핀들이나 높은 회전수를 고름.

06h_wet ≈ h/2, Ca = ηU/γ

도공 공정과 도포 두께

갭 코팅에서 젤은 정지한 블레이드와 움직이는 기재 사이를 통과함. 간극 안의 속도 분포는 기재가 끌고 가는 드래그 유동이 지배하므로 단면 평균 속도가 기재 속도의 절반이 되고, 유량 보존에서 기재 위에 남는 습윤 도포 두께는 간극의 절반 수준으로 근사됨. 건조·경화 후 두께는 여기에 고형분 비율을 곱해 얻음.

hwet ≈ h / 2   — 드래그 유동 근사
hdry = hwet × φ   — φ는 고형분 비율
도포량 [g/m²] = hdry[μm] × ρ[g/cm³]
Ca = ηU / γ       — 모세관 수, 점성력 대 표면장력
  • h블레이드 간극 [μm]
  • h_wet습윤 도포 두께 [μm]
  • φ고형분 비율 [무차원]
  • ρ건조막 밀도 [g/cm³]
  • Ca모세관 수 [무차원]. 점성력을 표면장력으로 나눈 비
  • U라인 속도 [m/s]. 분당 값은 60으로 나눠 씀
  • γ액체 표면장력 [N/m]. mN/m 값을 1000으로 나눠 씀

모세관 수는 도포막을 매끄럽게 펴려는 표면장력과 흐름을 끌고 가려는 점성력의 비임. 이 값이 커지면 코팅 비드 뒤쪽에서 흐름이 좌우로 갈라지며 진행 방향과 나란한 줄무늬가 남는데, 이 결함을 리빙이라 부름. 아래 계산기는 Ca = 0.01과 Ca = 1을 구간 경계로 잡아 안정·전이·리빙 세 구간을 표시함.

UV 경화부는 램프 출력과 개수를 라인 스피드로 나눈 누적 광량으로 경화도가 결정됨. 라인 속도를 올려 생산성을 확보하면 같은 램프 구성에서 누적 광량이 줄어들므로, 출력이나 램프 개수를 함께 올리지 않으면 경화도가 내려감. 두 변수가 한 분수 안에서 맞물려 있어 속도만 따로 조정할 수 없음.

  • 하드라이너 · 소프트라이너젤을 떼어낼 때의 박리력 차이를 이용해 나눠 씀. 두 라이너의 박리력이 달라야 한쪽만 먼저 떨어짐
  • 금속박 합지 필름금속면이 필요한 구조에 씀
  • 메시젤을 붙잡아 두어야 하는 전극에 덧댐

점도를 올려 얻으려는 효과와 도공 적성은 부딪힐 수 있음. 점증제와 용매를 서로 맞바꾸면 고형분을 유지한 채 점도만 움직일 수 있는데, 점도를 올리면 압축변형률이 내려가 경도가 개선되고 점착력은 올라가는 대신 면저항이 함께 올라감. 세 물성이 한 변수에 함께 걸려 있어 단일 최적점이 아니라 절충 구간이 생김.

점증제로 쓰는 PVP–비닐아세테이트 공중합체는 용액형과 분말형이 나뉘므로, 용액형의 고형분 값을 기준으로 분말 대 용매 비율을 환산해야 두 형태를 같은 조건으로 비교할 수 있음.
