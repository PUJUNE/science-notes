Field 04 · 화학 · 임피던스와 EIS

임피던스의 허수부에서 EIS까지

허수부에는 전류를 줄이는 요인과 위상을 밀어내는 요인이 함께 들어 있는가. 이 질문에서 출발해 Nyquist 선도와 Randles 등가회로, CPE와 Warburg까지 이어지는 정리임. 모든 그림은 브라우저에서 직접 계산해 그리며, 슬라이더로 조작할 수 있음.

Z(ω) = Z′ + jZ″ = |Z|∠θ   — 하나의 복소수가 크기와 위상을 동시에 담음

01Z = R + jX

크기와 위상은 R과 X가 함께 결정함

흔한 오해부터 정리해야 함. 실수부가 크기를, 허수부가 위상을 담당하는 구조가 아님. 전류의 진폭과 위상은 둘 다 R과 X가 함께 결정함.

|I| = V / √(R² + X²)   — 진폭
θ  = atan(X / R)       — 위상

X가 0이면 위상차도 0이고, R이 0이면 ±90°가 됨. 아래 복소평면에서 점을 직접 끌어 볼 것. R만 키우면 전류만 줄고 위상은 그대로이며, X만 키우면 두 가지가 동시에 나타남.

02P = ½ I² R

전류를 줄이는 두 가지 방식

R과 X 모두 전류를 감소시키지만 성격이 다름.

R 실수부 · 저항
  • 전류를 감소시킴
  • 에너지를 열로 소비함
  • P = ½ I² R
  • 전압과 전류가 동상
X 허수부 · 리액턴스
  • 전류를 감소시킴
  • 저장했다 되돌려줌
  • 평균 소비전력 = 0
  • 전압과 전류가 90° 어긋남

위 실험대에서 R을 낮추고 X만 키우면 전류 진폭은 줄어드는데 평균 소비전력도 함께 떨어짐. p(t) 곡선이 0선 위아래로 거의 대칭이 되면서 평균선이 0에 붙음.

두 효과는 별개의 요인 두 개가 아님. 에너지를 소비하지 않고 저장했다 되돌려주는 하나의 성질이 갖는 두 얼굴임. 전류가 전압과 90° 어긋나 있기 때문에 v·i의 평균이 0이 되고, 그 위상 어긋남이 곧 손실 없는 전류 제한으로 나타남.

03sign(X)

지연이라는 설명은 절반만 맞음

허수부의 크기가 위상차의 크기를, 부호가 지연인지 선행인지를 결정함.

04Z(ω)

EIS는 같은 임피던스를 반대 방향으로 씀

EIS(전기화학 임피던스 분광법)가 다른 물리를 쓰는 것은 아님. 일반 AC 회로 해석이 R·L·C를 알고 전류를 구하는 방향이라면, EIS는 반대로 Z(ω)를 측정해 놓고 안에서 무슨 반응이 일어나는지 역추정하는 방향임.

성립 근거는 전극 계면의 각 물리 과정이 서로 다른 시정수를 갖는다는 점임. 빠른 과정은 고주파에서만 따라오고, 느린 과정은 저주파에서만 응답할 시간이 있음. 그래서 주파수를 훑으면 과정들이 분리되어 보임.

가장 큰 차이는 비선형성임. 전기화학 반응은 Butler–Volmer 식처럼 전류가 전압에 지수적으로 의존하므로, EIS는 5~10 mV 정도의 작은 진폭만 걸어 동작점 주변에서 접선 기울기 dE/dI를 잼. 즉 EIS의 Z는 고정된 물성이 아니라 그 동작점에서의 미분 임피던스이고, 배터리 SOC가 바뀌면 같은 셀도 다른 곡선을 냄.

소자도 이상적이지 않음. R·L·C는 위상이 0°나 ±90°로 고정이지만 EIS에서는 그 사이 값이 흔함. Warburg는 Z = σ(1−j)/√ω 로 위상이 항상 −45°에 고정되는데, jω의 반정수 거듭제곱이라 R·L·C 조합으로는 만들 수 없음.

05−Z″ vs Z′

Nyquist 선도 — 주파수 스윕을 한 장에

가로축은 Z′(실수부), 세로축은 −Z″(허수부의 부호를 뒤집은 값)이며, 주파수를 훑으며 찍은 궤적임. 슬라이더를 조작하면 각 파라미터가 그림의 서로 다른 부분만 움직인다는 점이 드러남. 이 분리 가능성이 EIS를 쓰는 이유임.

06Rs + (Rct + Zw) ∥ Cdl

Randles 등가회로 — 전류가 흐를 길이 두 개임

전극에 전위를 걸면 전류가 흐를 길이 두 개로 갈림. 하나는 실제 산화·환원 반응으로 전자가 넘어가는 패러데이 경로이고, 다른 하나는 반응 없이 계면에 전하만 쌓이는 축전 경로임. 두 길이 같은 계면에서 동시에 열려 있으므로 병렬이고, 그 전에 이온이 벌크 전해질을 가로질러 와야 하므로 용액 저항이 직렬로 앞에 붙음.

  • Rs용액 저항. 이온이 벌크를 가로지르며 겪는 저항으로, 계면 바깥의 성질임.
  • Cdl이중층 용량. 계면에 전하가 쌓이는 축전 경로이며, 반응 없이 전류를 흘림.
  • Rct전하이동 저항. 반응 속도의 역수에 해당하고 교환전류밀도와 직결됨.
  • ZwWarburg 임피던스. 반응물이 계면까지 확산해 오는 데 걸리는 시간을 표현함.
Z(ω) = Rs + [ (Rct + Zw)−1 + jωCdl ]−1
Zw = σ(1 − j)/√ω   — 반무한 확산, 위상 −45° 고정
i₀ = RT / (n F Rct)   — 교환전류밀도
  • Rs용액 저항 [Ω]
  • Rct전하이동 저항 [Ω]
  • Cdl이중층 용량 [F]
  • σWarburg 계수 [Ω·s−1/2]. σ ∝ 1/(C√D)
  • ω각주파수 [rad/s], ω = 2πf
  • i₀교환전류밀도 [A/cm²]
  • R, T, n, F기체상수 8.314 J/(mol·K), 절대온도 [K], 전자수, Faraday 상수 96485 C/mol

07(Z′ − Rs − Rct/2)² + Z″² = (Rct/2)²

왜 반원인가 — 세 개의 극한

Warburg를 잠시 빼고(σ = 0) 계산하면 반원이 나오는 이유가 떨어짐.

Z = Rs + Rct / (1 + jωRctCdl)

Z′  = Rs + Rct / (1 + ω²τ²)    τ = Rct·Cdl
−Z″ = ωτRct / (1 + ω²τ²)

ω를 소거하면
(Z′ − Rs − Rct/2)² + (Z″)² = (Rct/2)²

중심이 (Rs + Rct/2, 0), 반지름이 Rct/2인 원의 방정식임. ω를 훑는다는 것은 이 원 위를 도는 일이고, 그래서 Nyquist에 반원이 그려짐.

  • ω → ∞ 고주파커패시터의 임피던스 1/jωCdl이 0으로 가서 계면을 단락시킴. 전류가 전부 Cdl로 새어 Rct와 Zw는 보이지 않고 남는 것은 Rs뿐이며, 이것이 왼쪽 절편임.
  • ω → 0 직류Cdl이 개방되어 전류가 전부 패러데이 경로로 감. Warburg가 없다면 오른쪽 절편 Rs + Rct에서 끝남.
  • 중간두 경로가 전류를 나눠 가지며 위상이 어긋나고, 그 궤적이 반원임. 정점(ωτ = 1)은 두 경로의 임피던스가 균형을 이루는 지점임.
  • 확산 꼬리Z_W = σ/√ω · (1−j)에서 실수부와 허수부 크기가 항상 같으므로 기울기 1, 즉 45° 직선임. 이 직선을 실수축까지 외삽한 절편은 Rs + Rct가 아니라 Rs + Rct − 2σ²Cdl로 왼쪽에 잡힘.

부식 연구에서 Rct가 크다는 것은 반응이 느리다는 뜻이므로 곧 방식 성능이 좋다는 의미이고, 배터리에서 사이클을 돌릴수록 반원이 커진다면 계면 열화가 진행 중이라는 신호임.

08ZCPE = 1 / [Q(jω)n]

CPE — 지수 n이 이상성의 척도가 됨

실측 반원은 매끈한 반원보다 납작하게 눌린 경우가 많음. 이상적인 커패시터는 위상이 −90°에 고정이지만, 표면 거칠기와 다공성, 시정수 분포가 있으면 위상이 그보다 얕게 잡힘. 이를 담기 위해 Cdl 자리에 상수위상요소(constant phase element)를 넣음.

ZCPE(ω) = 1 / [ Q (jω)n ]   위상 = −n·90°, 주파수에 무관하게 일정

n = 1 → 이상 커패시터 (Q = C)
n = 0.5 → Warburg 확산과 동일 (−45°)
n = 0 → 순저항 (Q = 1/R)

Ceff = [ Q · (Rs−1 + Rct−1)n−1 ]1/n   — Brug 식으로 유효 용량 환산
  • QCPE 계수 [S·sn = F·sn−1]. n=1일 때 정전용량과 같아짐
  • nCPE 지수 [무차원], 0 ≤ n ≤ 1. 이상성 척도
  • Ceff등가 정전용량 [F]. 표면적 비교에 쓰려면 이 환산이 필요함

주의 — n이 1에서 멀어질수록 Q의 단위 자체가 정전용량이 아니게 됨. 서로 다른 n을 가진 시료의 Q를 그대로 비교하면 물리적 의미가 없으므로, 표면적을 비교하려면 위의 Brug 식으로 Ceff로 환산한 뒤 비교해야 함.

09Randles ≠ 실측

실제 데이터가 교과서와 갈라지는 지점

Randles는 가장 단순한 이상화임. 실측 스펙트럼은 아래처럼 벗어남. 버튼을 눌러 비교해 볼 것.

이탈 사례

Z = Rs + Rct ∥ Cdl

가장 단순한 형태임. 하나의 매끈한 반원이 실수축 위에 정확히 앉음.

등가회로 피팅은 유일하지 않음. 서로 다른 회로 구조가 거의 같은 Nyquist를 낼 수 있어서, 피팅이 잘 됐다는 것만으로 그 회로가 실제 기구라고 주장할 수 없음. 보통 조건(전위·온도·농도)을 바꿔 가며 파라미터가 물리적으로 타당하게 움직이는지로 뒷받침함.

실험적 제약도 다름. 저주파일수록 한 사이클에 걸리는 시간이 길어져 1 mHz 한 점을 재는 데만 1000초가 걸림. 그 사이 배터리가 자가방전하거나 부식이 진행되면 정상상태 가정이 깨지고 Kramers–Kronig 검증에서 걸림. 일반 AC 회로 측정에서는 신경 쓸 일이 거의 없는 문제임.

10측정 설계

측정 수단이 다르면 같은 시료도 다른 값을 냄

임피던스는 측정 수단과 셀 구성에 따라 값이 달라지므로, 값을 비교하려면 조건을 먼저 맞춰야 함. LCR 미터는 단일 주파수에서 크기와 위상을 재고 potentiostat 기반 EIS는 주파수 스윕을 하는데, 전극 규격에서 요구하는 ACZ는 특정 주파수에서의 크기이므로 두 장비의 결과를 직접 비교하려면 같은 주파수·같은 진폭·같은 셀 구성이어야 함.

LCR 미터지정 주파수에서 |Z|와 θ, 또는 등가 R·C스윕이 없어 시정수 분리가 안 됨. 등가회로 모드(직렬/병렬) 선택에 따라 값이 달라짐

진폭을 키우면 안 되는 이유

전기화학 계는 비선형이므로 진폭이 커지면 응답에 고조파가 섞이고, 측정된 Z가 특정 동작점의 미분 임피던스라는 전제가 깨짐. 그래서 통상 5~10 mV 진폭을 씀. 신호가 묻힐 정도로 잡음이 크면 진폭을 올리는 대신 적산 횟수를 늘리거나 대역을 좁히는 쪽을 택함.

로그 보간 — 규격 주파수에서의 값 산출

규격이 요구하는 주파수가 측정 격자에 없을 때는 인접한 두 점을 로그–로그 공간에서 보간함. 임피던스는 주파수에 대해 멱함수적으로 변하는 구간이 많아 선형 보간보다 오차가 작음.

log|Z(f)| = log|Z₁| + (log f − log f₁) · (log|Z₂| − log|Z₁|) / (log f₂ − log f₁)
— f₁ < f < f₂ 인 인접 격자점 두 개를 사용함

Kramers–Kronig 검증 — 선형·인과·안정·시불변 조건을 만족하는 계라면 실수부와 허수부가 서로를 결정함. 측정 스펙트럼이 이 관계를 크게 벗어나면 측정 도중 계가 변했다는 뜻이므로, 등가회로 피팅에 들어가기 전에 데이터 자체를 버려야 함.
