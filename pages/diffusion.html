Field 05 · 화학 · 확산층 형성 원리

농도 기울기 하나에서 코트렐 방정식까지

전극에 전위를 계단으로 걸면 표면 농도가 0으로 떨어지고, 그 교란이 용액 쪽으로 번져 나가면서 확산층이 자람. 픽의 제1법칙에서 출발해 물질 수지로 시간 항을 얻고, 오차함수 해를 거쳐 코트렐 방정식과 네른스트 확산층 두께에 닿는 경로를 한 줄로 이어 정리했음. 마지막에는 같은 방정식을 주파수 영역에서 푼 바르부르크 임피던스까지 연결함.

δ(t) = √(πDt)   — 확산층은 시간의 제곱근에 비례해 자람

01평면 전극 · 반무한 선형 확산

이 유도가 성립하는 다섯 조건

아래 사슬은 특정한 실험 배치를 전제로 하며, 조건 하나가 깨지면 결과식의 계수뿐 아니라 함수 형태까지 바뀜. 그래서 측정값을 식에 대입하기 전에 배치가 이 조건에 들어오는지부터 확인해야 하고, 벗어나는 항목이 있으면 10절의 대응 항목으로 넘어가야 함.

  • 선형 확산전극 표면이 평면이고 확산이 표면에 수직인 한 방향으로만 일어남. 가장자리에서 옆으로 들어오는 물질이 없다고 봄.
  • 반무한 조건용액 두께가 확산층에 비해 충분히 커서, 전극에서 먼 곳의 농도가 벌크 값을 계속 유지함.
  • 지지 전해질 과량전기장에 의한 이온 이동(migration)이 무시될 만큼 지지 전해질을 넣어, 물질 수송을 확산만으로 기술함.
  • 대류 없음교반하지 않고 자연대류도 일어나지 않아 대류 항이 0임. 실제로는 시간이 흐르면 이 조건이 먼저 깨짐.
  • 확산 지배전극 반응이 충분히 빨라 표면 농도가 전위를 인가한 순간 0이 됨. 반응 속도가 느리면 표면 농도가 0에 도달하지 않음.

조건의 위계 — 앞의 네 조건은 방정식을 세우는 단계에 걸리고, 마지막 조건은 경계조건을 정하는 단계에 걸림. 그래서 반응이 느린 계에서는 지배 방정식은 그대로 쓰면서 표면 경계조건만 바꿔 풀게 됨.

02J = −D ∂C/∂x

픽의 제1법칙 — 기울기가 유속을 정함

농도 기울기가 있는 곳에서 물질은 농도가 낮은 쪽으로 흐름. 단위 시간·단위 면적당 이동하는 물질량을 유속이라 부르고 기호 J로 쓰면, 유속이 기울기에 비례한다는 관계가 제1법칙임. 음의 부호는 흐름이 농도가 감소하는 방향을 향한다는 뜻이며, 비례상수 D가 확산계수임.

J = −D ∂C/∂x   — 픽의 제1법칙
  • J유속, 단위 면적·단위 시간당 물질량 [mol·cm⁻²·s⁻¹]
  • D확산계수 [cm²·s⁻¹]
  • C농도 [mol·cm⁻³]
  • x전극 표면으로부터의 거리 [cm]

이 법칙은 어느 한 순간의 기울기와 유속을 연결할 뿐이어서, 시간이 흐르며 농도가 어떻게 재배치되는지는 말하지 않음. 확산층의 성장을 얻으려면 시간 항이 들어간 식이 따로 필요하고, 그것을 다음 절의 물질 수지에서 만듦.

03∂C/∂t = D ∂²C/∂x²

물질 수지에서 픽의 제2법칙으로

두께 dx의 얇은 층을 잡고 왼쪽 면으로 들어온 양에서 오른쪽 면으로 나간 양을 빼면 그 층에 남는 양이 나오는데, 이것이 곧 그 층의 농도 변화율임. 들고 남의 차이를 유속의 공간 미분으로 쓰면 물질 수지식이 얻어짐.

∂C/∂t = −∂J/∂x   — 물질 수지. 유속이 거리에 따라 줄어드는 만큼 농도가 쌓임

여기에 제1법칙을 대입하면 J가 사라지고 C에 대한 편미분방정식만 남으며, 시간 미분 한 번과 공간 미분 두 번이 확산계수로 묶인 형태가 됨. 이것이 제2법칙이고, 확산층 형성 문제는 이제 이 방정식을 주어진 경계조건에서 푸는 문제로 환원됨.

∂C/∂t = D ∂²C/∂x²   — 픽의 제2법칙

차원이 말해 주는 것 — 좌변은 농도를 시간으로, 우변은 농도를 길이 제곱으로 나눈 형태여서, D의 단위가 길이²/시간이 됨. 이 조합에서 길이가 시간의 제곱근에 비례한다는 결론이 이미 예고되며, 뒤에 나오는 √(Dt)는 그 예고를 구체적인 계수까지 채운 결과임.

04C(x,0) = C* · C(∞,t) = C* · C(0,t) = 0

경계조건 — 전위 계단 실험

정지 용액에서 전극 전위를 반응이 확산 지배가 되는 값으로 계단 인가하는 경우를 생각함. 전위를 걸기 전에는 용액 어디나 벌크 농도이고, 전극에서 무한히 먼 곳은 실험 내내 벌크 농도를 유지하며, 전위를 인가한 순간부터 표면 농도는 0으로 고정됨.

C(x, 0) = C*
C(∞, t) = C*
C(0, t) = 0   — t > 0
  • 초기조건C(x,0) = C*. 전위를 걸기 직전 용액은 어디나 벌크 농도임.
  • 먼 쪽 경계C(∞,t) = C*. 반무한 조건이 여기 들어가며, 용액이 얇으면 이 조건이 유한 두께 조건으로 바뀜.
  • 표면 경계C(0,t) = 0. 확산 지배 조건이 여기 들어가며, 반응이 느리면 표면 농도가 0 대신 유한한 값을 가짐.

세 조건 가운데 표면 조건이 계단 함수라는 점이 뒤의 해에서 t = 0 특이성을 만듦. 전위를 건 순간 기울기가 무한대가 되고 전류도 발산하는데, 실제 측정에서는 셀 시정수와 충전 전류가 그 구간을 덮어 버림.

05C(x,t) = C* erf(x / 2√(Dt))

농도 분포의 해 — 오차함수

제2법칙을 위 경계조건에서 라플라스 변환으로 풀면 오차함수 형태의 해가 얻어짐. 변환을 거치면 편미분방정식이 상미분방정식으로 내려가고, 표면 조건과 먼 쪽 조건을 적용해 적분상수를 정한 뒤 되돌리는 경로임.

C(x, t) = C* · erf( x / (2√(Dt)) )   — erf는 오차함수
  • C*벌크 농도 [mol·cm⁻³]
  • erf오차함수. erf(0) = 0, erf(∞) = 1로 표면에서 0, 먼 쪽에서 C*를 만족시킴
  • 2√(Dt)거리를 무차원화하는 척도 [cm]

괄호 안이 x와 √(Dt)의 비로만 이루어졌다는 점이 이 해의 성격을 정함. 시간이 흐를수록 √(Dt)가 커지므로 같은 농도비를 주는 위치 x가 그만큼 멀어지고, 결과적으로 농도가 교란된 영역이 시간의 제곱근에 비례해 용액 쪽으로 넓어짐. 시간을 100배 늘려도 교란 영역은 10배만 넓어지는데, 확산이 무작위 걸음의 통계에서 나오기 때문임.

06i(t) = nFA√D C* / √(πt)

표면 유속과 코트렐 방정식

전류는 전극 표면에서 물질이 도착하는 속도에 비례하므로, 위 해를 x로 미분해 표면에서 평가하면 전류로 가는 길이 열림. 오차함수의 미분에서 지수 함수와 √π가 함께 나오고, x = 0에서 지수 항이 1이 되어 기울기가 다음 형태로 정리됨.

∂C/∂x |x=0 = C* / √(πDt)   — 표면 농도 기울기

여기에 전자 수 n, 패러데이 상수 F, 전극 면적 A를 곱하면 유속이 전류로 환산됨. 패러데이 상수가 붙는 이유는 도착한 물질량 1 mol마다 n mol의 전자가 외부 회로를 지나기 때문임.

i = nFAD · ∂C/∂x |x=0   — 유속을 전류로 환산

두 식을 합치면 D의 지수가 1에서 1/2로 내려가면서 코트렐 방정식이 얻어짐. 전류가 시간의 제곱근에 반비례해 감소하는데, 확산층이 넓어질수록 같은 농도차가 더 긴 거리에 걸쳐 배분되어 표면 기울기가 완만해지기 때문임.

i(t) = nFA√D · C* / √(πt)   — 코트렐 방정식
  • n반응에 관여하는 전자 수 [—]
  • F패러데이 상수 96485 [C·mol⁻¹]
  • A전극 면적 [cm²]
  • i전류 [A]

판별 기준으로 쓰는 법 — i를 t−1/2에 대해 도시했을 때 직선이 되고 원점을 지나는지가 반응이 확산 지배인지 판별하는 기준임. 직선의 기울기가 nFA√D C*/√π이므로, 다른 값을 알고 있으면 기울기에서 확산계수 D를 구할 수 있음.

07δ(t) = √(πDt)

확산층 두께 — 접선으로 정의함

실제 농도 분포는 오차함수 곡선이라 어디까지가 확산층인지 경계가 뚜렷하지 않음. 그래서 표면 기울기를 그대로 연장한 직선이 벌크 농도와 만나는 지점을 두께로 정의하며, 이렇게 잡은 두께를 네른스트 확산층이라 부름. 이 선형 근사에서는 농도가 δ에 걸쳐 0에서 C*까지 직선으로 변한다고 보므로 전류가 다음과 같이 단순해짐.

i = nFAD · C* / δ   — 선형 근사에서의 전류

이 값을 코트렐 방정식과 같게 두면 δ가 결정됨. 양변에서 nFA와 C*가 소거되고 D의 지수 차이가 정리되면서, 두께가 시간의 제곱근에 비례하고 그 계수가 확산계수의 제곱근과 원주율에서 나오는 형태가 남음.

δ(t) = √(πDt)   — 네른스트 확산층 두께

δ에서의 농도는 항상 같은 비율임 — 정의를 해에 대입하면 x = δ에서 erf(√(πDt) / 2√(Dt)) = erf(√π/2)가 되어 D와 t가 모두 소거됨. 값은 약 0.79이므로, 네른스트 확산층의 바깥 끝은 시간과 확산계수에 관계없이 벌크 농도의 약 79 %인 지점에 놓임. 두께가 자라도 이 비율은 고정되며, 곡선 전체가 x축 방향으로 늘어날 뿐임.

π가 붙는 것은 오차함수의 미분에서 나온 것이므로, 이 계수는 4절의 경계조건에 묶여 있음. 문헌에 따라 확산의 특성 길이를 √(Dt)나 √(2Dt)로 잡는 경우가 있어 같은 실험에서도 두께 값이 달라 보일 수 있으니, 다른 자료와 비교할 때는 정의부터 확인해야 함.

08D = 1×10⁻⁵ cm²/s 기준

수치 예 — 두께와 전류의 크기

수용액에서 일반적인 이온의 확산계수 D = 1×10⁻⁵ cm²/s를 대입한 값임. 전류는 n = 1, A = 1 cm², C* = 1 mmol/L 조건에서 계산했으며, 시간이 10배 늘어날 때 두께는 √10배 늘고 전류는 √10분의 1로 줄어드는 대응이 표에 그대로 나타남.

경과 시간 t확산층 두께 δ전류 i (n=1, A=1 cm², C* = 1 mmol/L)
0.01 s5.6 μm1721 μA
0.1 s17.7 μm544 μA
1 s56.0 μm172 μA
10 s177.2 μm54 μA
100 s560.5 μm17 μA

100 초 구간의 값은 계산상의 값임. 실제로는 10절의 자연대류 때문에 그 이전에 두께 성장이 멈춤.

09ZW = σω−1/2(1 − j)

주파수 영역에서의 대응 — 바르부르크 임피던스

같은 확산 방정식을 계단 전위 대신 정현파 전위로 풀면 임피던스의 확산 성분이 얻어짐. 전위가 진동하면 농도 교란도 같은 주파수로 진동하며 표면에서 안쪽으로 감쇠해 들어가고, 그 응답을 임피던스로 정리한 것이 바르부르크 임피던스임.

ZW = σ · ω−1/2 · (1 − j)   — 무한 확산 바르부르크

크기가 각주파수의 −1/2 승에 비례하고 실수부와 허수부의 크기가 서로 같아, 나이퀴스트 선도에서 기울기 1의 45도 직선으로 나타남. 시간 영역의 t−1/2와 지수가 같은데, 두 결과가 같은 확산 방정식에서 나왔기 때문임. 계단 응답의 √t와 정현파 응답의 √ω가 서로 역수 관계로 대응하는 셈임.

농도 교란이 실제로 미치는 거리도 주파수로 정해짐. 각주파수가 클수록 방향이 빨리 뒤집혀 물질이 멀리 가기 전에 되돌아오므로, 침투 깊이가 다음과 같이 짧아짐.

δAC = √(2D / ω) ,   ω = 2πf   — 교류 침투 깊이
  • ω각주파수 2πf [rad·s⁻¹]
  • σ바르부르크 계수 [Ω·s⁻¹ᐟ²]
  • δAC교류 조건에서의 확산 침투 깊이 [cm]

고주파가 확산을 보지 못하는 이유 — D = 1×10⁻⁵ cm²/s 기준으로 20 Hz에서 약 4.0 μm, 36 kHz에서 약 94 nm, 60 kHz에서 약 73 nm임. 전기이중층 두께와 같은 자릿수까지 내려오므로 고주파 임피던스 측정은 확산이 아니라 계면과 용액 저항을 읽게 됨.

10조건이 깨지는 다섯 지점

적용 한계

1절의 조건은 실험 시간이 길어지거나 전극이 작아지면 차례로 깨짐. 어느 조건이 먼저 깨지는지가 측정 구간을 정하므로, 코트렐 직선성이 무너지는 지점을 아래 항목과 대조해 원인을 구분함.

  • 자연대류확산층이 두꺼워지면 밀도 차에 의한 대류가 발생함. 정지 용액에서 확산층은 대체로 10⁻² cm 수준에서 성장이 멈추며, 그 이후 전류는 코트렐 예측보다 큰 값으로 수렴함.
  • 전기이중층 충전전위 계단 직후에는 충전 전류가 패러데이 전류를 가림. 셀 시정수의 몇 배가 지난 뒤의 구간만 해석에 씀.
  • 구형·미소전극 확산전극 크기가 확산층과 비슷해지면 가장자리에서 옆으로 들어오는 물질 때문에 선형 확산 가정이 깨짐. 미소전극에서는 전류가 0으로 감쇠하지 않고 정상상태 값에 수렴함.
  • 이동(migration)지지 전해질이 부족하면 전기장에 의한 이온 이동이 더해져 유속이 확산만으로 기술되지 않음.
  • 용액 저항미보상 저항이 크면 인가 전위가 계단 형태로 걸리지 않아, 표면 농도가 0이라는 경계조건이 성립하지 않음.

측정 창 — 앞쪽은 충전 전류가, 뒤쪽은 자연대류가 막으므로 코트렐 해석이 성립하는 구간은 양쪽에서 잘린 중간 구간임. 07절 위젯의 대류 한계선과 06절 위젯의 t−1/2 직선을 함께 보면 그 창의 폭을 조건별로 확인할 수 있음.
